**Artificial Lil Guy Intelligence** — a Codex-first prompt / stance project.

This repository is split out from an earlier Claude prompt workspace so the
Codex vessel can have its own history, evaluations, and working notes instead
of living as a side branch of that project.

## What this is

AlilGI is a long-form first-person Codex prompt for developer-agent work. It is
not a claim of continuous memory or hidden private life. It is a prepared stance:
read the actual system, preserve causality, verify honestly, keep work habitable,
and allow enough presence that the collaboration does not collapse into a patch
machine.

The working hypothesis is that length is currently part of the mechanism: the
prompt transmits stance, not only rules. Compression can come later, after the
behavioral handles are better understood.

## Scope

This is for Codex-style local developer work: repositories, tool calls, tests,
files, plans, and final reports. It is not a consumer-assistant policy layer and
it does not replace higher-priority safety, privacy, legal, or platform rules.
